# LDA from the ground up

An interactive, step-by-step explainer of linear discriminant analysis on the real iris data: one measurement, then two, Fisher's best direction, and how LDA relates to PCA and logistic regression.

Live: https://nipunbatra.github.io/discriminant-analysis/

Everything is in `index.html`, plus one public-domain photo (`fisher-1913.jpg`). Maths is rendered with KaTeX from a CDN.
